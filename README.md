# Start here

You receive one C++ source file, boa.cpp, plus the assignment and manual testing guide PDFs. Open assignment.pdf first. The deadline and collaboration/AI policy are set by your instructor.

Compile boa.cpp with your normal C++ compiler or IDE. The starter intentionally has compiler errors. After repairing those, run the program and use menu options 0 through 5. The manual guide gives the exact input, correct results, observed buggy results, and prerequisites for each test.

There is no Python or separate student checker. Recompile after each edit, type the test inputs, compare the records with the guide, and rerun earlier cases after making changes.

Parts A, B, and C are labeled in the same file. Put Part D answers in the comment at the top. Submit only your completed boa.cpp.
